# 通达杯

通达杯团队协作仓库，用于集中管理项目代码、文档与任务。

## 获取项目

接受仓库协作邀请后，克隆项目：

```bash
git clone https://github.com/faradayhezz/tongda-cup.git
cd tongda-cup
```

## 协作方式

1. 使用 [Issues](https://github.com/faradayhezz/tongda-cup/issues) 记录任务、问题和讨论。
2. 同步最新的 `main`，再创建自己的工作分支，例如 `feature/功能名称` 或 `fix/问题名称`。
3. 完成修改后提交 Pull Request，说明变更内容和验证结果。
4. 邀请队友审阅，通过后合并到 `main`。

每次提交聚焦一个明确的修改。密钥和本地环境配置应保存在忽略的 `.env` 文件中；需要共享配置格式时，使用不含密钥的 `.env.example`。
