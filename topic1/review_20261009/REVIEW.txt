通达杯题1队友项目审核记录
2026年10月9日  MATLAB R2023a

当前范围
审核 PR #2 上传的 v2 至 v8_1。v1 仍在补传，放到最后核对，不推送覆盖其内容。
这批版本是原始测距基线的渐进实验；默认估计器保持不变，实验候选需要显式调用。

发现并修正的问题
1. 双径粗搜索的外层 tau 与嵌套损失函数变量共享，损失函数把 ns 初值改成秒，
   破坏后续初值。已分开 delayStartNs 与 delayS，并记录24组合法粗搜索初值；
   8份双径实现同步修正，相关实验重新运行，算法阈值没有按新结果重新调参。
2. 实验性 PBR-only 输出被统计为 RTT 回退。新增 OutputMode 和 PBRFallbackRate，
   明确联合融合、RTT单独回退、PBR单独回退与不可用四种状态。
3. run_compare_v1 原先只跑默认分支并要求手工改配置。现成对运行两种模式，
   使用同一随机种子，验证输入观测一致，不修改共享配置文件。
4. 各版本 README 指向旧目录，引用文档文件名转码错误，v8_1 回归说明调用旧函数名。
   已修正入口与链接，并明确 reference_results 只是原始基线副本，不能代表新模块验证。

实际验证
v2至v8_1分别10项自检通过，共80项执行；新增8项策略测试通过，包含不可用输入、
模糊候选、修正幅度、时钟漂移、输出类型，以及共同硬件时延偏差的负面对照。
31个不同MATLAB源码静态检查无诊断。最新版本完整基线7200包与540次敏感性扫描，
独立种子六场景7200包成对回归，4频率计划×4信道×3SNR×2距离×20次=1920包多径实验，
144包V3/V4/V5候选测试、864包默认/实验分支比较、480包其他入口冒烟测试。
总计18348包仿真测试（不计校准观测）。另验证保存IQ处理接口。
逐次结果和汇总经Python标准库独立重算，回退统计分母与四种状态比例一致。

结果解读
独立六场景回归中V8切换次数为0，结果与基线相同：证明本次未引入输出回归，
但没有证明V8解决原始轻多径或校准漂移。轻多径合并RMSE约1.246m，漂移约2.392m。
在强回波、60ns、幅度0.4的独立实验（3/15m，0/15/30dB，每频率计划120包）中，
16MHz跨度基线4.318m、V8 1.448m；32MHz跨度基线4.409m、V8 0.389m；
64MHz跨度基线4.485m、V8 0.124m。此收益依赖频率跨度与观测几何。
未加门控的V2会过拟合：16MHz LOS的RMSE由0.073m变成0.693m；强晚回波下
64MHz的V3/V7也可能比基线差。因此保持实验入口独立，不将新策略自动替换默认估计器。

适用限制
全部为Simulation only。跨载频理想相位参考、已知距离校准和共同调度时间轴
未通过Pluto硬件验证；64MHz是跨频点总跨度，不是20MSPS接收机瞬时带宽。
共同线性硬件相位/时延偏差仍与距离混淆，曲率、相干度和BIC门控不能保证识别它。
六场景中校准漂移超过1m错误仍存在；软件自检通过不等于所有信道达到测距精度要求。
